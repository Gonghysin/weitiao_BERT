# 技术文档

## 项目概述

本项目基于BERT预训练模型，实现了医疗对话意图分类系统。通过对IMCS-DAC数据集的处理和微调，模型能够准确识别医疗对话中的16种不同意图类别，为智能医疗问答系统提供核心支持。

## Google BERT中文模型详解

### 1. BERT模型架构

BERT (Bidirectional Encoder Representations from Transformers) 是由Google AI团队于2018年提出的预训练语言模型，具有以下核心特点：

#### 模型结构
- **基础架构**：基于Transformer编码器堆叠
- **参数规模**：
  - BERT-Base：12层Transformer块，12个注意力头，768维隐藏层，共110M参数
  - BERT-Large：24层Transformer块，16个注意力头，1024维隐藏层，共340M参数
- **中文BERT-Base**：采用与原始BERT-Base相同架构，但使用中文词表训练

#### Transformer编码器层
1. **多头自注意力机制(Multi-Head Self-Attention)**
   - 使用12个注意力头并行捕捉不同位置的依赖关系
   - 每个注意力头计算Query(Q)、Key(K)、Value(V)三个映射
   - 注意力分数计算：Attention(Q,K,V) = softmax(QK^T/√d_k)V

2. **前馈神经网络(Feed-Forward Network)**
   - 由两个线性变换组成：FFN(x) = max(0, xW_1 + b_1)W_2 + b_2
   - 中间激活函数为GELU(Gaussian Error Linear Unit)

3. **残差连接与层归一化**
   - 每个子层都使用残差连接：Output = LayerNorm(x + Sublayer(x))
   - 防止深层网络退化和梯度消失问题

### 2. BERT中文预训练过程

BERT-Base-Chinese模型基于大规模中文语料库进行了预训练，具体过程如下：

#### 预训练语料库
- **语料来源**：中文维基百科、百度百科、新闻数据等
- **数据规模**：约5.4GB原始文本数据，包含数亿汉字
- **预处理**：去除HTML标记、繁简转换、标点规范化等

#### 词表与分词
- **词表大小**：21,128个词汇，采用字级别分词
- **特殊标记**：[CLS]（序列开始）、[SEP]（分隔符）、[MASK]（掩码标记）、[PAD]（填充标记）等
- **分词策略**：主要基于字符级tokenization，而不是WordPiece（英文BERT使用）

#### 预训练任务
1. **掩码语言模型(Masked Language Model, MLM)**
   - 随机掩盖输入中15%的token
   - 在被掩盖的token中：80%替换为[MASK]、10%替换为随机token、10%保持不变
   - 训练模型预测被掩盖位置的原始token

2. **下一句预测(Next Sentence Prediction, NSP)**
   - 训练样本包含句子对(A,B)
   - 50%概率B是A的真实下一句，50%概率B是语料库中随机句子
   - 模型预测B是否为A的真实下一句

#### 训练参数
- **批次大小**：256个序列
- **序列长度**：最大512个token
- **优化器**：Adam，β1=0.9，β2=0.999
- **学习率**：1e-4，使用线性衰减
- **训练步数**：1,000,000步
- **预训练设备**：TPU Pod

### 3. BERT在下游任务中的应用

BERT模型可以通过微调适应各种下游任务，具体应用方式如下：

#### 模型适配方法
1. **文本分类（如本项目的意图分类）**
   - 使用[CLS]标记的表示，通过全连接层映射到标签空间
   - 整个BERT参数与分类层一起微调

2. **序列标注（如命名实体识别）**
   - 使用每个token的最终隐藏状态
   - 添加全连接层映射到标签空间

3. **问答与阅读理解**
   - 使用两个独立的分类器预测答案的开始和结束位置
   - 输入为[CLS] 问题 [SEP] 文档 [SEP]格式

4. **句子对分类（如语义相似度）**
   - 输入格式为[CLS] 句子A [SEP] 句子B [SEP]
   - 使用[CLS]标记表示进行分类

### 4. 本项目的BERT微调流程

本项目在Google预训练的中文BERT基础上进行微调，完成医疗对话意图分类任务，具体微调流程如下：

#### 准备阶段
1. **数据准备**
   - 清洗IMCS-DAC数据集文本
   - 规范化处理，统一标点符号、繁简转换
   - 保留对话上下文信息，实现更准确的意图理解

2. **模型初始化**
   - 加载预训练的bert-base-chinese模型
   - 添加分类层，将[CLS]输出映射到16个意图类别
   - 初始化分类层参数

#### 微调策略
1. **参数冻结**
   - 可选择性冻结BERT底层参数（如前6层）
   - 第一阶段仅训练顶层Transformer和分类层
   - 第二阶段可选择性解冻所有层，使用较低学习率全面微调

2. **优化设置**
   - 使用AdamW优化器，学习率设为2e-5，权重衰减为0.01
   - 应用学习率预热策略，前10%训练步数线性增加学习率
   - 之后线性衰减学习率
   - 使用梯度裁剪防止梯度爆炸

3. **训练过程**
   - 批次大小设为16（可根据GPU显存调整）
   - 训练4个epoch（经验值，可通过验证集提前停止）
   - 使用交叉熵损失函数
   - 根据验证集F1分数保存最佳模型

#### 创新点
1. **上下文集成**
   - 将对话上下文集成到BERT输入中
   - 使用特殊标记分隔不同轮次对话
   - 修改token_type_ids区分上下文和当前文本

2. **医疗领域适应**
   - 针对医疗对话特点，优化分词和表示学习
   - 考虑医疗术语和专业表达

## 核心模块说明

### 1. 数据处理模块 (`data_processing.py`)

数据处理模块提供了全面的文本预处理功能，包括文本清洗、规范化、分词、上下文保留和停用词过滤等。

#### 主要功能：

* **文本清洗** (`clean_text`): 
  - 移除HTML标签
  - 清理多余的空白字符和换行符
  - 过滤多余的特殊符号
  - 移除非中文字符和乱码

* **文本规范化** (`normalize_text`):
  - 全角转半角处理
  - 标点符号统一（统一使用中文标点）
  - 繁简体转换

* **BERT分词处理** (`tokenize_with_bert`):
  - 支持上下文保留的分词处理
  - 添加特殊标记区分上下文和当前文本
  - 记录上下文位置信息

* **停用词过滤** (`filter_stopwords`):
  - 基于停用词表过滤分词结果
  - 支持自定义或默认停用词表

* **数据集处理** (`process_dataset`，`process_dataset_with_tokenization`):
  - 对整个IMCS-DAC数据集进行批量处理
  - 支持简单处理或带分词和上下文的高级处理
  - 结果保存为JSON格式

### 2. 模型架构模块 (`model_architecture.py`)

模型架构模块定义了基于BERT的医疗对话意图分类模型结构，以及相关的辅助功能。

#### 主要组件：

* **对话意图分类模型** (`BertForDialogueActClassification`):
  - 继承自`BertPreTrainedModel`
  - 加载BERT基础模型作为编码器
  - 添加分类头（线性层）将[CLS]输出映射到16个类别
  - 支持计算交叉熵损失进行训练

* **模型加载功能** (`load_model`):
  - 支持从本地或Hugging Face在线加载预训练模型
  - 配置num_labels、output_attentions等参数

* **优化器与调度器** (`get_optimizer_and_scheduler`):
  - 创建AdamW优化器，针对不同参数组设置不同权重衰减
  - 创建带有预热策略的学习率调度器

* **对话意图标签**:
  - 定义16类医疗对话意图标签
  - 提供标签与索引之间的映射

### 3. 模型训练模块 (`train_model.py`)

模型训练模块实现了完整的训练、验证和预测流程，支持多种参数配置。

#### 主要功能：

* **数据集加载** (`IMCSDataset`):
  - 自定义PyTorch Dataset类
  - 支持加载预处理数据或即时处理
  - 维护对话上下文信息

* **模型训练** (`train`):
  - 支持冻结BERT部分层参数
  - 实现完整训练循环，包括梯度裁剪、参数更新
  - 定期在验证集上评估模型性能
  - 保存最佳模型和训练统计图表

* **模型预测** (`predict`):
  - 加载训练好的模型进行预测
  - 保持对话上下文以提高预测准确性
  - 输出预测结果到JSON文件

* **命令行界面**:
  - 提供丰富的命令行参数配置训练过程
  - 支持设置学习率、批次大小、训练轮数等参数
  - 提供模型路径、输出目录等配置选项

### 4. 模型下载工具 (`fetch_model.py`)

提供了自动从Hugging Face下载BERT预训练模型的功能，简化环境配置。

## 对话意图分类类别

本项目支持识别以下16种医疗对话意图类别：

1. Other - 其他
2. Request-Symptom - 症状询问
3. Inform-Symptom - 症状告知
4. Request-Basic_Information - 基本信息询问
5. Inform-Basic_Information - 基本信息告知
6. Request-Etiology - 病因询问
7. Diagnose - 诊断
8. Inform-Precautions - 注意事项告知
9. Request-Existing_Examination_and_Treatment - 已有检查和治疗询问
10. Inform-Existing_Examination_and_Treatment - 已有检查和治疗告知
11. Request-Drug_Recommendation - 药物建议询问
12. Inform-Drug_Recommendation - 药物建议告知
13. Request-Examination_and_Treatment - 检查和治疗询问
14. Inform-Examination_and_Treatment - 检查和治疗告知
15. Request-Healthcare_Institution - 医疗机构询问
16. Inform-Healthcare_Institution - 医疗机构告知

## 技术特点

### 1. 上下文感知处理

本项目的一个关键特点是对医疗对话上下文的保留与处理：

- 每条话语在处理时都会考虑之前几轮对话内容
- 使用特殊标记区分不同轮次的上下文和当前文本
- 对话上下文信息被整合到BERT的输入中
- 预测时也会维护对话上下文，确保准确理解当前话语意图

### 2. 模型微调策略

针对医疗领域专业性强的特点，采用了以下微调策略：

- 支持冻结BERT底层参数，仅训练上层和分类头
- 使用较小的学习率保持预训练知识
- 应用梯度裁剪防止梯度爆炸
- 采用warmup学习率调度提高训练稳定性
- 根据F1分数保存最佳模型

### 3. 数据处理优化

针对中文医疗文本的特点，实现了专门的处理流程：

- 全面的文本清洗确保去除噪声
- 中文标点符号统一化
- 繁简体转换确保文本一致性
- 可选的停用词过滤

## 使用指南

### 环境配置

1. 安装依赖包：
```bash
pip install torch transformers matplotlib sklearn tqdm zhconv numpy
```

2. 下载预训练模型：
```bash
python src/fetch_model.py
```

### 数据准备

1. 将IMCS-DAC数据集（JSON格式）放置在`src/datasets/`目录下
2. 可选：准备中文停用词表，放置在`src/datasets/stopwords/chinese_stopwords.txt`

### 数据预处理

运行数据处理脚本，生成处理后的数据集：
```bash
python src/data_processing.py
```

### 模型训练

使用以下命令进行模型训练：
```bash
python src/train_model.py --do_train --model_path src/models/bert-base-chinese --train_file src/datasets/IMCS-DAC_train.json --dev_file src/datasets/IMCS-DAC_dev.json --output_dir src/models/fine-tuned --num_train_epochs 4 --train_batch_size 16 --freeze_bert_layers 6
```

主要参数说明：
- `--do_train`: 执行训练任务
- `--model_path`: 预训练模型路径
- `--train_file`: 训练数据文件
- `--dev_file`: 验证数据文件
- `--output_dir`: 输出目录
- `--num_train_epochs`: 训练轮数
- `--train_batch_size`: 训练批次大小
- `--freeze_bert_layers`: 冻结BERT前N层

### 模型预测

使用以下命令进行预测：
```bash
python src/train_model.py --do_predict --model_path src/models/bert-base-chinese --predict_model_path src/models/fine-tuned/best_model_epoch_X --test_file src/datasets/IMCS-DAC_test.json --output_file prediction_results.json
```

主要参数说明：
- `--do_predict`: 执行预测任务
- `--predict_model_path`: 微调后的模型路径
- `--test_file`: 测试数据文件
- `--output_file`: 预测结果输出文件

## 性能评估

模型在验证集上的性能通过以下指标评估：
- 准确率（Accuracy）
- 加权F1分数（Weighted F1-score）
- 分类报告（每类别的精确率、召回率、F1分数）

训练过程中会生成损失曲线和准确率曲线图表，帮助分析模型训练过程。
